# Planner

Planner pessoal em uma única página web, com tema off-white:

- **Mensal** — calendário com as tarefas de cada dia, separadas em "A fazer" e "Concluídas".
- **Semanal** — no estilo de agenda tradicional: um dia embaixo do outro, com linhas para escrever as tarefas (ex.: `14h Dentista`).
- **Finanças** — entradas, saídas, saldo do mês, gastos por categoria e limite mensal.
- **Hábitos** — hábitos editáveis, marcação diária e desempenho ("3 vezes em 5 dias", sequência).
- **Notificações** — avisos ao concluir tarefas e hábitos, com opção de desfazer.

Os dados ficam salvos no próprio navegador (localStorage).

## Usar no iPhone

Abra o link do GitHub Pages no Safari → Compartilhar → **Adicionar à Tela de Início**.
